「內心小劇場」：讓衝動小人和理智小人替你吵出決定的 AI 機器人

遇到「要不要買」「要不要熬夜」「要不要聯絡前任」這類糾結，內心小劇場會叫出衝動小人和理智小人吵一輪，再由裁判依你當下的狀態下判決。題目完全開放，勝負由程式規則算出來，不是固定理智派贏。

動機：糾結很日常，但現成工具只會給標準答案

我們每天都在做小決定，糾結的往往不是答案本身，而是「想放縱」和「該克制」兩種聲音互相拉扯。一般聊天機器人只會給理性建議，缺少這個拉扯的過程，也沒有考慮你今天累不累、情緒有多上頭。

痛點具體情況內心小劇場的對策
腦中兩種聲音在吵想聯絡又怕後悔，想熬夜又怕明天爆炸讓兩個小人把雙方理由吵出來，內容有梗也好讀
一般建議太制式回答永遠是「理性評估後再決定」先用規則依情緒、後悔、疲累等通用條件評分，再下判決
結果總是理智派贏，很無聊固定導向克制，使用者很快就不想用勝負由分數決定，條件允許時衝動派會贏，並給「合理放縱」方案
每次決定彼此獨立不知道自己這週已經放縱幾次記錄戰績，下次判決會參考本週放縱次數

使用流程：糾結一件事的完整過程

以「想聯絡前任」為例。使用者自我評分：後悔機率 4 分、期待快樂 3 分、情緒上頭 5 分、今天疲累 4 分，而且訊息一發出就收不回。

步驟使用者操作內心小劇場的輸出
1. 輸入寫下糾結的事，填七項通用條件（放縱次數選填）確認輸入
2. 基礎評分無，自動進行Python 函式算出基礎分 +3，並列出每項加減分
3. 開吵無小衝先講一句，逐字打出
4. 輪流發言每次換人前，選一個關鍵字、自己輸入一句話，或讓他自由發揮輪到的一方拿你給的論點去攻擊對方，來回最多六句
5. 裁判微調無，自動進行裁判整理雙方論點，依辯論內容微調分數，上限 ±2
6. 判決無，自動進行依最終分數判決，附合理放縱或折衷方案
7. 檢查與記錄回覆「接受」或「不接受」Reflection 檢查判決與分數一致，再更新本週戰績

條件評分規則由 Python 函式執行。七項條件對任何題目都適用，不綁定金錢。分數為正偏向理智派，為負偏向衝動派：

條件加減分
後悔機率 4 到 5 分+2
後悔機率 3 分+1
後悔機率 1 到 2 分−1
做了很難收回+1
會影響明天或長期目標+1
情緒上頭（4 到 5 分）+1
期待快樂 4 到 5 分−1
今天很累（4 到 5 分）−1
本週已放縱 3 次以上（選填，留空不計分）+1

上表算出的是基礎分。辯論結束後，裁判依雙方被補的論點微調分數，Python 把微調值一律截在 ±2 以內，微調後的最終分數 +2 以上判理智派勝，−1 以下判衝動派勝，0 到 +1 為平手，由裁判給折衷方案。這樣使用者的每次介入都有影響，但 LLM 不能推翻整個評分。

使用技術

沿用課堂用過的套件：AISuite 串接 Groq API，模型為 groq:openai/gpt-oss-120b，介面用 Gradio，API key 放在 Colab 的 Secrets。

課堂技巧在專案中的用途
System prompt 角色設定小衝、小理、裁判各有一份人設，口氣和立場不同
Tool UsePython 函式 score_conditions() 依條件算分，LLM 不自己算
Planning裁判先整理雙方論點，再依分數寫判決和折衷方案
Reflection檢查判決是否與分數一致、有沒有編造數字，不合格就重寫
Gradio輸入表單、對話顯示、戰績紀錄

評分函式的核心如下，LLM 只拿到結果：

def score_conditions(regret, irreversible, affects_goal, emotion, joy, tired, indulged=None):
    s = 2 if regret >= 4 else 1 if regret == 3 else -1
    s += 1 if irreversible else 0
    s += 1 if affects_goal else 0
    s += 1 if emotion >= 4 else 0
    s += -1 if joy >= 4 else 0
    s += -1 if tired >= 4 else 0
    s += 1 if indulged is not None and indulged >= 3 else 0
    return s

def final_verdict(base, llm_adjust):
    adj = max(-2, min(2, llm_adjust))   # LLM 的微調一律截在 ±2
    s = base + adj
    verdict = "理智派勝" if s >= 2 else "衝動派勝" if s <= -1 else "平手"
    return {"base": base, "adjust": adj, "score": s, "verdict": verdict}

風險與備案

風險備案
使用者輸入沉重話題（傷害自己等）偵測關鍵字時不跑小劇場，改顯示溫和提醒，建議找信任的人或專業單位談談（台灣安心專線 1925）
LLM 裁判微調過頭或編造理由Python 把微調值截在 ±2，Reflection 檢查理由是否引用辯論中實際出現的論點
自我評分很主觀，結果可能不準定位為幫你看清自己的狀態，不是替你做決定，判決附「僅供參考」
內容屬個人資料不保存到伺服器，示範只用虛構資料
Groq 免費額度限速或回傳空白重試一次，仍失敗就用模板台詞補上
